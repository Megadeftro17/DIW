# Guía de Estilo Visual - Bikes-LE

## Paleta de Colores
- **Principal (Navegación / Pie):** `#1b365d` (Azul corporativo)
- **Acento / Acción:** `#27ae60` (Verde sostenible)
- **Fondo General:** `#f4f6f8` (Gris claro)
- **Texto Principal:** `#2c3e50` (Gris muy oscuro)
- **Alerta / Error:** `#e74c3c` (Rojo)

## Tipografía
- **Familia principal:** Arial, Helvetica, sans-serif.

## Componentes Reutilizables (.css)
- `.destacado`: Utilizado para resaltar información clave u ofertas.
- `.tarjeta-producto`: Usado en la ficha de cada producto para estructurar la información.
- `.boton-compra`: Aplicado a los botones de llamada a la acción y envío de formularios.
- `.error-formulario`: Mensajes de aviso/validación visual bajo los campos.
- `.centrado`: Clase de utilidad para alinear textos al centro.
